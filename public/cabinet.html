Отправка из личных кабинетов отключена администратором. Можно подключить Telegram и подготовить черновики; запуск станет доступен после настройки обработчика.

Доступ и приватность

Здесь доступны только ваши подключения и рассылки. MCP не получает Telegram-сессию, QR-код, список диалогов или общую историю переписки. Доступ администратора сервера сохраняется.

01 Подключение Telegram

Укажите свой @username, затем войдите по QR-коду.

В мобильном Telegram откройте Настройки → Устройства → Подключить устройство.

Подключение Instagram

Войдите в Instagram и разрешите подключить профессиональный аккаунт Business или Creator.

Пароль вводится на странице Instagram. В Outreach он не передаётся.

Что доступно после подключения

Профиль сохраняется только в вашем кабинете. Здесь можно проверить подключение и отключить аккаунт.

Отправка и чтение Direct пока не добавлены. Официальный API позволяет отвечать на обращения, но не начинать холодную переписку с произвольными пользователями.

03 Доступ через MCP

Права на сообщения действуют только для выбранных рассылок. Отправка возможна после подготовки точного плана и вашего подтверждения. Доступ к подключению Telegram и другим кабинетам не предоставляется.

Права
Разрешённые рассылки

Токен показывается один раз. Скопируйте его в настройки MCP. Не отправляйте в обычный чат. 


            

              
              
            

            

          

          

          

            Настройка MCP
            

              Локальный MCP-адаптер этого проекта запускается командой
              node src/mcp/server.js. Укажите в его окружении
              OUTREACH_BASE_URL — адрес этого же сервиса,
              MCP_API_TOKEN — созданный токен с префиксом
              ocp_. Он автоматически предоставит только разрешённые
              инструменты.
            

            

              Адрес сервиса для подключения:
              https://outreach.korotkov.dev.
              Используйте HTTPS, чтобы токен передавался с шифрованием.
            

            

              Отзыв токена закрывает дальнейший доступ через MCP. Уже
              подтверждённую очередь нужно остановить отдельно.
            

          

        

        

          
04 Почта и восстановление

          

          

            
            
          

          

          
Сменить пароль

          

            Отправим одноразовую ссылку на подтверждённую почту кабинета. После
            смены пароля нужно будет войти заново; прежние сеансы и MCP-токены
            будут отозваны, очередь этого кабинета остановится.
          

          
          

        

      

    

    
      

        
Новая рассылка

        
      

      

        
        
        

          
          
          
        

        

          По будням, по московскому времени. Лимит общий для профиля; между
          сообщениями — не менее 3 минут.
        

        

          
        

      

    
    
      

        
Новое сообщение

        
      

      

        Сохраните текст для получателя. Отправку можно будет отдельно проверить
        и подтвердить.
      

      

        

          
        

        
        

          
        

        
      

    
    
      

        
Импорт сообщений

        
      

      

        Вставьте подготовленный массив JSON: address, recipient_id, name, body,
        source_url, permission_kind, permission_evidence. Импорт сохраняет
        сообщения без отправки.
      

      

        
      

    
    
      

      

        Проверьте адресатов, тексты и время. Подготовка ничего не отправляет.
