OUTREACH DESK

Личный кабинет

Вход

Отправка из личных кабинетов отключена администратором. Можно подключить Telegram и подготовить черновики; запуск станет доступен после настройки обработчика.

Здесь доступны только ваши подключения и рассылки. MCP не получает Telegram-сессию, QR-код, список диалогов или общую историю переписки. Доступ администратора сервера сохраняется.

Подключение Telegram

Укажите свой публичный username. Войдите по QR в мобильном Telegram: Настройки → Устройства → Подключить устройство.

Рассылки и очередь

По будням, время московское. Лимит общий для одного Telegram-профиля, включая все его рассылки. Минимальный интервал — 3 минуты.

Добавить черновик
Импорт черновиков JSON

Массив объектов с полями address, recipient_id, name, body, source_url, permission_kind и permission_evidence. Импорт сохраняет черновики без отправки.

История отправок

В переписке отображаются исходящие из сервиса и ответы через функцию «Ответить» на них. Обычные сообщения без привязки к этой цепочке не импортируются. Их владелец проверяет в Telegram самостоятельно.

Доступ через MCP

Токен действует только для выбранных рассылок. Отправка возможна после подготовки точного плана и вашего подтверждения. Доступ к подключению Telegram и другим кабинетам не предоставляется.

Права
Разрешённые рассылки

Токен показывается один раз. Скопируйте его в настройки MCP. Не отправляйте в обычный чат. 


            
          

          

          

            Настройка MCP
            

              Локальный MCP-адаптер этого проекта запускается командой
              node src/mcp/server.js. Укажите в его окружении
              OUTREACH_BASE_URL — адрес этого же сервиса,
              MCP_API_TOKEN — созданный токен с префиксом
              ocp_. Он автоматически предоставит только разрешённые
              инструменты.
            

            

              Для текущего адреса http://213.171.10.147:3000 также
              задайте OUTREACH_ALLOW_HTTP=true в окружении MCP. При
              HTTP токен передаётся без шифрования.
            

            

              Отзыв токена закрывает дальнейший доступ через MCP. Уже
              подтверждённую очередь нужно остановить отдельно.
            

          

        

      

    

    
      

      

        Проверьте адресатов, тексты и время. Подготовка ничего не отправляет.
